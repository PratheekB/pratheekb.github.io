Connect to GitHub

This page publishes by saving files to the site's GitHub repository, so it needs a token from you. You only do this once on each device. The token stays in this browser and is never added to the site.

  1. Open GitHub → new fine-grained token.
  2. Name it (say, "Blog"), and set an expiry (a year is fine).
  3. Under Repository access, choose Only select repositories and pick pratheekb.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Generate it, copy it, and paste it here.
